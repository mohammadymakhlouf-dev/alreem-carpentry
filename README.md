# منجرة الريم

برنامج عربي لتسجيل حسابات لنا وعلينا، الأصناف والدفعات، وعرض المتبقي وطباعة كشف الحساب أو حفظه PDF من نافذة الطباعة.

## التشغيل
افتح index.html في متصفح حديث أو استضفه على HTTPS. لا يحتاج إلى تثبيت مكتبات.

## البيانات
تُحفظ الحسابات في متصفح الجهاز محليًا، ولا تُرفع إلى GitHub أو تتزامن بين الأجهزة. صدّر نسخة احتياطية بانتظام من داخل البرنامج. عند الانتقال إلى عنوان موقع جديد، صدّر النسخة من الموقع القديم واستعدها على الجديد.
